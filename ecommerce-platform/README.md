# 电商网站平台

这是一个完整的电商网站解决方案，包含以下核心子系统：

## 核心功能模块

### 1. 后台管理系统
- 用户管理
- 商品管理
- 店铺管理
- 权限控制

### 2. 支付系统
- 订单支付处理
- 支付渠道集成
- 退款处理
- 支付安全

### 3. 履约系统
- 库存管理
- 物流跟踪
- 发货处理
- 售后服务

### 4. 订单管理系统
- 订单创建与处理
- 状态跟踪
- 订单查询
- 统计分析

## 技术架构

### 后端技术栈
- Spring Boot
- MyBatis
- MySQL
- Redis
- RabbitMQ

### 前端技术栈
- React
- Ant Design
- Axios

## 项目结构

```
ecommerce-platform/
├── backend/          # 后端服务
│   ├── admin/        # 后台管理服务
│   ├── payment/      # 支付服务
│   ├── fulfillment/  # 履约服务
│   └── order/        # 订单服务
├── frontend/         # 前端应用
│   ├── admin/        # 后台管理界面
│   ├── customer/     # 客户端界面
│   └── components/   # 公共组件
└── docs/             # 文档
```

## 快速开始

### 环境要求
- JDK 1.8+
- Node.js 14+
- MySQL 5.7+
- Redis

### 启动步骤

1. 克隆项目
2. 配置数据库连接
3. 启动各微服务
4. 构建前端应用
